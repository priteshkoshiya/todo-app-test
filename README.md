# nextjs-static starter v12

Tailwind CSS v3 is preinstalled. `tailwind.config.js` maps theme tokens
(`bg-bg`, `text-primary`, `font-heading`, …) to the CSS variables in
`app/globals.css` and provides the global classes (`.container`, `.section`,
`.btn`, `.btn-primary`, `.btn-secondary`, `.eyebrow`, `.visually-hidden`),
focus-visible, reduced-motion and overlay scrollbar styles.
